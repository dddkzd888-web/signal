# 起势 · 美股信号筛选

用你的两段富途公式，筛选“放量黄色 K 线 + 副图 BBUY 红柱”。连接本机已登录的 OpenD，展示真实日线与对应信号。

## 打开网站

双击本目录的 **启动筛选器.command**，浏览器会打开 **http://127.0.0.1:8765**。保持终端与 OpenD 运行。

首次运行会准备本目录的独立环境并安装依赖，需要网络。已经为当前电脑准备好环境。程序使用 Mac 的 `/usr/bin/python3`（本机验证版本为 Python 3.9），不需要 Node.js。

若端口占用，可从终端运行：`SCREENER_PORT=8766 ./启动筛选器.command`。如果筛选器已运行，重复打开会复用它。

## 筛选步骤

1. 左侧输入美股代码，或导入 TXT / CSV。CSV 支持 `symbol` 或 `code` 列。普通代码会自动加 `US.`，支持股票与 ETF；示例股票池包含 20 只，不是全市场。
2. 默认放量为 **成交量 > 20 日均量 × 1.5**，均量含当天，与富途源码一致。勾选“均量仅使用此前交易日”可排除当天。
3. 默认副图红柱为 **BBUY**：`EMA((C+L+H)/3,6)` 上穿其 5 周期 EMA。这个红柱和箭头是交叉信号，不等于 MACD 正柱。
4. 默认两种信号同日出现；可选择前后 1–5 个交易日配合。只在两种信号都已出现之后算作匹配，没有使用未来信号。
5. 默认最近 5 个交易日。可改到最多 60 日，查看更早出现的组合。额外条件默认关闭。
6. 点击“扫描更新行情”；之后只改规则时，点击“应用条件 · 重算缓存”即可，不重复占用行情额度。

## 看结果和图表

- 候选列表显示放量倍数、组合日期、距 VWAP 的幅度。全部结果也包含未命中、失败和历史不足的股票。
- 点击股票查看 K 线、VWAP、成交量、原副图与 MACD；KDJ 可开启。
- 黄色蜡烛表示放量，红涨绿跌；副图 BBUY 红柱与向上箭头发生在同一日。
- 点击底部“历史组合信号”卡片，会跳到该事件并高亮日期。这里显示的是历史事件，不代表仍然处于启动初期。
- 鼠标悬停查看同一天的数据；拖动查看历史；用按钮或 Ctrl+滚轮缩放。
- 导出包含代码、信号日期、参数和数据截止日期的 CSV；选择“全部结果”后导出包含失败原因。

## 数据口径

仅使用美股常规交易时段、前复权、已收盘日线。按纽约交易日历判断收盘，考虑夏令时、节假日和提前收盘。当前交易日尚未收盘时，结果截至上一个已收盘交易日。

首次尽量获取 5 年历史；首次扫描可能花几分钟，因为行情请求串行限速。每只新请求证券可能占用历史行情额度，多次获取同一证券是否占用以 OpenD 的额度状态为准。额度不足或权限错误会逐只显示，程序不会用模拟数据替代。

缓存保存在本目录 `data/cache.sqlite`。同一天直接复用缓存；下一交易日获取重叠数据，若发现价格/量的历史变化，则重新获取该证券完整历史，以避免混用复权数据。

新上市证券至少需要 30 根且满足所选均量窗口才参与核心筛选。少于 330 根时，长周期趋势线会注明参考范围不足。指标递推初值、富途加载的历史长度和复权设置可能导致数值差异，尚未与富途逐项数值对照。

源码中所谓“主力资金”粉柱是价格衍生计算，没有实际资金流来源。指标名字里的“强拉升”“安全区”等仅保留原公式语义，不代表验证过的预测或概率。

## 本机运行与维护

页面和服务只监听 `127.0.0.1`，仅建立行情连接，不创建交易接口。所有图表资源本机提供；行情更新需要网络与 OpenD。服务器关闭后，股票池、规则和行情缓存仍保留。

运行验证：`.venv/bin/python -m unittest discover -s tests -v`。

重启：在网站终端按 Ctrl+C，再双击启动脚本。更新 OpenD 登录后，可点网站顶部的重新连接按钮。

## 两级候选排序

默认包含第二优先候选。第一优先：近期黄色放量 K 线与 BBUY 红柱配合。第二优先：近期 BBUY 红柱出现，配合窗口内没有黄色放量；页面注明缺少放量确认。排序先看优先级，再看日期。可关闭“包含第二优先”只看第一优先。附加过滤仍生效；要求放量上穿 VWAP 时不纳入第二优先。仅有黄色放量、没有 BBUY 不入选。CSV 包含优先级，第二优先的放量日期留空。
